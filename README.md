# História do Futebol Internacional 1872-2025

Dashboard interativo com 49k jogos e 47k gols da história das seleções.

**O que eu fiz:**
- Limpeza de 328 seleções históricas usando `former_names.csv`
- EDA: distribuição de gols por minuto, evolução de pênaltis/contra por década
- Raio-X do Brasil: artilheiros, maiores vítimas (Chile 105 gols sofridos), maiores carrascos (Argentina 41 vitórias)

**Stack:** Python, Pandas, Plotly, Streamlit

**Insights:**
- 9,3% dos gols na década de 2020 são de pênalti vs 3% nos anos 40
- 80-90 min é o intervalo com mais gols na história
- Ronaldo (Fenômeno) lidera o Brasil no dataset com 39 gols
